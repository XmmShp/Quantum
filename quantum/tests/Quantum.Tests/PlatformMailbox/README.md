# Platform mailbox integration fixture

MobileBridgeMailbox.cs is a snapshot with LF line endings of the platform mailbox implementation used by desktop end-to-end tests. It is compiled only into the test assembly. provenance.json pins the exact source hash and base commit; sourceState identifies the coordinated, uncommitted platform change. Keep the copy identical after line-ending normalization when updating it. No sibling repository checkout is required to run these tests.
